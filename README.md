# tomedo-KI-Skills

Ein Handbuch zur KI-Nutzung in tomedo und die Skills dazu zum Herunterladen.
**Die Seite dazu: https://cupky.github.io/tomedo-skills/**

Im Repository liegt die Seite mit den Dateien zum Herunterladen: die zehn
Skills einzeln und als Sammelpaket sowie das Handbuch als Markdown und PDF.

## Geltungsbereich

Die Angaben stammen aus einer Installation. Aussagen der Form „Feld leer" oder
„X von Y" beschreiben diese Referenzinstallation, nicht tomedo.

## Korrekturen

Korrekturen als Issue willkommen, besonders Abweichungen in fachlichen Angaben.
Bitte keine Patientendaten, keine Bildschirmfotos mit Klarnamen und keine
Auszüge aus echten Akten in Issues einstellen — sie wären öffentlich sichtbar.
